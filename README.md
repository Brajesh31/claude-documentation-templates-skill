# DocumentationTemplates

Choose, tailor, and produce maintainable templates for README files, API references, architecture notes, code comments, changelogs, runbooks, and AI-readable project documentation.

## What this skill covers

- Practical guidance for documentation templates workflows.
- A consistent process for reviewing requirements, making decisions, and validating results.
- Use `SKILL.md` as the primary reference.

## Installation

Add this skill directory to the skills location supported by your AI coding assistant, then make the skill available to the assistant.

## Usage

Invoke the skill for tasks related to documentation templates. Provide the relevant project context, constraints, and expected outcome. Review generated changes before applying them.
